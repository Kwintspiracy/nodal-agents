## Prerequisites

**Node.js ≥ 22** is required (the package declares `engines: node >= 22`). `npm`
ships with Node, so if you have a recent Node you already have npm. No external
Postgres, no Redis, no cloud config.

## Install

```bash
npm install -g nodal-agents
nodal-agents up
```

## First run: the setup wizard

The very first time you run `nodal-agents up` — when no `~/.nodalai/config.json`
exists yet — the CLI launches an interactive setup wizard before starting anything.
It walks you through:

1. **LLM provider** — which model you want to use, picked from a list of presets
   (Ollama, LM Studio, Jan AI, llama.cpp, vLLM, Anthropic, OpenAI, OpenRouter…).
2. **Endpoint URL** — the provider's base URL (pre-filled with a sensible default
   you can accept or override).
3. **Model** — the CLI fetches the available models from the endpoint and lets you
   pick one; if it can't reach the endpoint, you type the model name instead.
4. **API key** — prompted only for remote providers that require one.
5. **Network mode** — Loopback (localhost only, no auth) or LAN (accessible on your
   network, sign up with email + password).

Your answers are saved to `~/.nodalai/config.json`. Re-run the wizard any time with
`nodal-agents init`.

Once the wizard finishes (or on every subsequent run, since the config now exists),
the CLI spawns an embedded Postgres on a free port, applies migrations, seeds the
system skills, and starts the runner (`:3001`) and the dashboard (`:3000`). Open
[localhost:3000](http://localhost:3000).

Your data lives at `~/.nodalai/` — wipe it any time with `rm -rf ~/.nodalai`. Stop
the stack with `nodal-agents down`.

## Connect a model

Open **LLM Providers** in the dashboard and paste an API key for any provider
(Anthropic, OpenAI, Google, DeepSeek, MiniMax, OpenRouter…) — or point it at a
local model (LM Studio / Ollama). Setup is one key per provider; each agent then
picks its own model on top.

## Create your first agent

1. Go to **Agents → New agent**.
2. Give it a name, a personality / system prompt, and pick its model.
3. Optionally assign it [skills](/docs/reference/skills), connectors, or MCP servers.
4. Send it a task from the dashboard chat — or wire it to Telegram.

## Update

```bash
nodal-agents update
```

Checks npm for the latest version, stops the stack, installs `nodal-agents@latest`,
and restarts automatically. Your data is preserved.

## Other commands

```bash
nodal-agents logs [web|runner|postgres]
```

Tails logs for the given service, or all three if you omit the argument.

```bash
nodal-agents reset --yes
```

Deletes all Nodal-Agents data and config. Omit `--yes` to get a confirmation
prompt first.
