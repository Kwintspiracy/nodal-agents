## Install

<Tabs items={['Install', 'Update']}>

<Tab value="Install">

```bash
npm install -g nodal-agents
nodal-agents up
```

Opens the dashboard on `localhost:3000` with an embedded Postgres — no external database, no Redis, no config files to edit.

</Tab>

<Tab value="Update">

```bash
nodal-agents update
```

Stops the stack, installs `nodal-agents@latest`, and restarts. Your data is preserved.

</Tab>

</Tabs>

<Callout type="info">
  Requires **Node 22+**. Everything — conversations, memory, credentials — stays in `~/.nodalai/` on
  your machine.
</Callout>

## What you get

- **Local-first** — single command, embedded Postgres; your data never leaves your machine.
- **Any model, per agent** — Anthropic, OpenAI, Google, native DeepSeek & MiniMax, OpenRouter, or local (LM Studio / Ollama). One key per provider; each agent picks its own model.
- **Orchestrators that finish** — route to one specialist and resume on its result, or fan out independent work to many sub-agents in parallel and compile the answer.
- **Memory that compounds** — persistent facts auto-injected into every job, plus chat continuity across sessions.
- **Self-improving agents** — an opt-in [learning loop](/docs/concepts/learning-loop): after a substantial job an agent reflects and writes itself a reusable skill; a curator consolidates them.
- **Skills, connectors & MCP** — assign reusable [skills](/docs/reference/skills), connect Gmail / Drive / Notion, and add MCP servers over HTTP _and_ stdio.
