Notable releases, newest first. Pre-1.0: minor versions can carry breaking
changes. Every release is published to npm as `nodal-agents` and tagged on
GitHub — upgrade in place with `nodal-agents update` (your data is preserved).

## v0.7.9 — The Design System Release · Jul 13, 2026

The whole dashboard now speaks one visual language, enforced so it can't drift — plus a rebuilt Google Gemini provider.

- **One consistent interface.** Every button, field, badge, pill, menu, and modal across the app is now a shared component. A lint rule makes raw, off-system elements fail the build, so the consistency holds for good — verified page by page, in light and dark.
- **Editing always happens in a modal.** No more inline accordions that shove the page around; every list edit opens a clean, non-dismissable dialog with a single Save/Cancel footer.
- **One grammar for row actions.** Icon-only square buttons with tooltips, one verb per icon, Delete always last, no hidden kebab menus.
- **End-to-end channel setup guides.** Connecting Discord, Slack, WhatsApp, or Telegram now walks you all the way to the first message — token setup, the ownership DM, the invite, and a "verify it works" step — in a properly formatted modal.
- **Google Gemini, rebuilt.** The native and OpenRouter Gemini paths were reworked (thought-signature round-trip on tool calls, native thinking config, 3.x catalog) so tool-calling agents run correctly on Gemini.
- **Polish.** The Settings page is now the same width as every other page, and Learned Skills uses the same per-agent assign/unassign toggle list as the Skills page — so you can finally unassign a learned skill.

## v0.7.8 — The Everywhere Release · Jul 12, 2026

Your agents now live everywhere you already talk, and they can no longer misrepresent what they did while they were there.

- **Discord, Slack, and WhatsApp join Telegram.** Every agent speaks on all four channels through one shared identity and delivery model, with the same approval rules everywhere.
- **Event triggers.** A scheduled job knows exactly how long it slept and catches up correctly. An external service can now start a job directly through an incoming webhook.
- **Approval authority goes to the owner, every time.** Scheduled deliveries, webhooks, and approval cards can no longer land in the wrong chat. The Chat page also got a full redesign.
- **Agents can't deny their own actions anymore.** A grounded action record keeps a true history of what ran, and a delegating agent's thread now shows what its sub-tasks actually did.
- **Moonshot/Kimi joins as a native provider**, alongside a shared schema sanitizer for OpenRouter.
- **Onboarding, revamped.** The setup interview moves to a hidden chat thread, you choose which messaging channels to connect, and models now show which tools they actually support.
- **A second communication-layer security audit**, covering recipient authorization, file containment, SSRF protection, and a properly gated ask path.

## v0.7.5 — The Trustworthy Orchestrator · Jul 8, 2026

Approvals you can actually read, delegation that behaves, and a second full security pass.

- **Approvals that explain the real impact.** The line shown before you approve a gated action now genuinely reflects what the command does.
- **Shared files and delegated delivery, gated properly**, along with new rules for multi-turn conversations.
- **Delegation with discipline.** Sub-agents follow a stricter loop, and a memory truth check keeps them honest.
- **A second full security audit**: 9 high and 11 medium findings fixed, a CI guard that blocks hardcoded secrets, and a context-window fix for local and custom models.

## v0.7.2 — The Allowlist Release · Jul 7, 2026

A big security and reliability audit, plus control over who can talk to your agents on Telegram.

- **Telegram allowlist.** The first person to message your bot becomes its owner. Anyone else needs approval before their message starts a job, reviewable from a new dashboard view.
- **A major security and reliability hardening pass** across multi-tenant isolation, approval and OAuth flows, cron scheduling, and file handling.
- Memory's background curator got sturdier, with fixes to scheduling, retention, and boot-time reliability.

## v0.7.0 — The Curator Release · Jul 2, 2026

Memory that scales: full-text search, real ranking, and a curator that keeps it tidy.

- **Full-text memory search**, ranked by relevance instead of recency alone.
- **Curate it yourself.** Star a memory to boost its importance, pin the ones that must never be pruned, or add one by hand.
- **Consistent autonomy wording** between onboarding and Settings, one source of truth instead of two.

## v0.6.8 — The Web Search Release · Jul 1, 2026

- **Web search, built in.** A unified router tries multiple providers automatically and falls back to a free option, on by default with no setup required.
- **Onboarding honors your answers.** The autonomy level you choose in the interview is now actually applied, and your first ROOT agent gets its grants turned on.

## v0.6.7 — The Fresh Install Release · Jul 1, 2026

- **Fixed a fresh-install boot break.** A bundled dependency was breaking boot on brand-new installs. The package is slimmer and boots clean again.

## v0.6.6 — The Fresh Machine Release · Jul 1, 2026

- **First boot gets more time to breathe.** The health-check budget on a brand-new machine grew to 5 minutes, so a slower first boot no longer times out before it's healthy.

## v0.6.5 — The Browser-First Release · Jul 1, 2026

Setup happens in the browser now, not the terminal.

- **No more terminal wizard.** First run opens straight into the browser with local-trust on by default. The onboarding interview also finishes there, with a reliable Continue button and an always-available Skip.
- A cleaner install: bundled dependencies mean no more install-time deprecation warnings.

## v0.6.4 — The First Run Release · Jun 30, 2026

A critical fix for anyone installing for the first time.

- **Fresh installs no longer lock you out.** A bug in the first-run flow could strand a brand-new install before onboarding finished. That flow is restored.

## v0.6.3 — The Toolbar Release · Jun 30, 2026

The dashboard finally feels like one product, and Telegram can send anything.

- **One header, one toolbar across every page.** Plus a new Runs view for delegated work and a rebuilt Skills page.
- **Full Telegram media support.** Agents can now send video, audio, voice notes, and any document, not just images.
- **Poyo joins the connector marketplace** for quick image generation, and the marketplace grid is now alphabetized with verified badges.
- Small fixes: a Weekly/Daily toggle on the home activity chart, and consistent "installed" wording on Skills and Connector tiles.

## v0.6.2 — The Recall Release · Jun 28, 2026

Your agents remember — within a conversation, and across everything they've ever done.

- **Conversations that hold the thread.** Session memory measures a pause from when the reply was _delivered_, not when the job started — so a slow task no longer makes a quick follow-up look like an hour of silence. The idle reset widened (30 min → 4 h), the history budget grew, the reply's tail is kept, and a job that failed but spoke to you stays in the thread. Measured amnesia on a real 122-message conversation: 39% → 13%.
- **Two-tier memory.** Injected memory is ranked by relevance to the current task; every job's transcript is full-text searchable on demand via the new `search_history` tool (durable recall, zero standing context cost); and a background memory curator distills oversized facts, merges duplicates, and prunes the stale — never touching what you entered by hand.
- **3D & creative connectors.** Blender, Unity, Unreal Engine, KeyShot, and Photoshop (cross-platform) join the MCP marketplace under a new Creative category, each with a real brand icon.
- A longer MCP tool timeout (renders don't time out at 60 s) and a CI flake fix.

## v0.6.1 — The Vision Release · Jun 27, 2026

Send a picture on Telegram and your agents can actually look at it.

- **Inbound images.** A photo sent on Telegram now starts a job — it was silently dropped before. The image is saved to your shared workspace (`telegram/<chat>/<job>.<ext>`), reachable by the agent's file tools, and handed to the model — so "describe this image" works.
- **Vision routing, by real capability.** Each model's image support is read from the providers themselves (OpenRouter + models.dev) and surfaced in the orchestrator's team view. A text-only orchestrator routes the picture to a vision-capable teammate — the image travels with the delegation — or tells you plainly if none can see it. No guessing.

## v0.6.0 — The Clarity Release · Jun 25, 2026

Approvals that explain themselves, chat hand-offs that stay faithful, and session memory that knows when a conversation is over.

- **Approvals in plain language.** Every gated action (shell command, skill script, bundle write) leads with the agent's own one-line explanation of _what_ it's doing and _why_ — plus a ⚠️ impact line when it deletes, installs, or spends — instead of a wall of raw shell. On Telegram and in the dashboard.
- **Faithful chat hand-offs.** When the dashboard chat escalates your request to a worker, your exact words travel with it — no more silently reworded instructions. A 30-minute idle gap starts a fresh conversation, so a thread you return to hours later doesn't drag yesterday's context into a new request.
- **Role-aware delivery.** Delegated workers hand results back to their orchestrator instead of double-delivering to you; the "how to structure and where to send" lives in a reusable skill, so a bare "research X" is enough.
- A shared workspace link in Settings, and a complete README rewrite.

## v0.5.5 — The Autonomy Release · Jun 23, 2026

Real autonomy levels, a curated community catalogue, and agents that stop making things up.

- **Three real autonomy levels** per workspace ROOT — `propose-confirm`, `destructive_gate` (auto-run ordinary work, still gate anything destructive), and `fully_autonomous` — enforced at execution time, not just in the UI.
- **A 40-skill Community catalogue** — install any of them with one click, every path verified.
- **Google Calendar** connector, and an entity-scoped skill store.
- **Anti-confabulation team blocks** — orchestrators describe their real team instead of inventing teammates, and delegated sub-agents suspend/resume cleanly across an approval.

## v0.5.0 — The Self-Improving Release · Jun 15, 2026

A closed learning loop, native frontier-OSS endpoints, and one orchestrator that does both delegation styles.

- **A closed learning loop (opt-in).** After a substantial job an agent reflects and writes itself a reusable skill; a weekly curator consolidates and prunes them. Review, assign, or revoke every learned skill from the dashboard.
- **Native DeepSeek & MiniMax** endpoints alongside OpenRouter — pick the route per key, with reasoning round-tripped across tool calls so reasoning models don't degrade mid-task.
- **Unified orchestrator** — every orchestrator gets both delegation styles and commits to one per request: route to a specialist and resume on its result, or fan work out to a parallel task board and compile it.
- **Install any community `SKILL.md`** from GitHub, skills.sh, or ClawHub — pure HTTPS, SSRF allow-list, zip-slip guard, scripts flagged and never run.
- **A real-dollar cost cap** per job (from the provider's actually-billed cost), plus a no-false-success guard that refuses to report "done" when an action failed.

## v0.4.4 — The Context Release · Jun 4, 2026

Long jobs stay inside the window, failures become diagnosable, and delivery only happens when there's somewhere to deliver.

- **Context compaction** — stale tool output is evicted before the window overflows, keeping the recent turns intact.
- **Real provider errors** — failures surface the actual upstream message and persist the full transcript, instead of an opaque "provider returned error."
- **Channel-aware delivery** — an agent only reaches for `telegram_send_message` when there's a resolvable recipient, killing phantom sends on dashboard/API jobs.

## v0.4.3 — The Reasoning Release · Jun 3, 2026

- **Reasoning models, round-tripped.** A reasoning model's hidden chain-of-thought is now replayed across tool calls (via the official OpenRouter SDK), so MiniMax M3, DeepSeek, and friends keep reasoning on multi-turn tasks instead of stalling.
- Fixed an orchestrator that would narrate an action without performing it (poisoned history — escalations are now replayed _with_ their `run_task`).

## v0.3.7 — The Root Agent Release · May 30, 2026

- **A self-extending ROOT agent.** Designate your first orchestrator as the workspace ROOT and let it create skills, create agents and assign them, and stand up MCP servers + connectors on your behalf — each gated by a per-grant toggle and an autonomy level.
- Provisioning verifies before it writes (an MCP server is connected and its tools listed first); skill authoring is grounded in the workspace's real tools.

## v0.3.0 — The Workspaces Release · May 28–29, 2026

- **Multiple isolated workspaces** on one install (personal vs work), switchable from the sidebar — each with its own agents, skills, connectors, jobs, and memory.
- **Office files** — edit Excel in place, create Word & PowerPoint, inside the agent's workspace.
- **One-command upgrade** (`nodal-agents update`) with a boot version notice.
- A reworked Skills library (Assigned / Custom / Built-in) and a richer connector + MCP marketplace.

## v0.1.0-beta — First public beta · May 13, 2026

The first published build: a local-first, multi-agent platform on embedded Postgres — team orchestration, per-agent models, persistent memory, Telegram, and connectors, in two commands.
