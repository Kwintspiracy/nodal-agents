**À signaler —** lint vert avec 25 warnings; suites unitaires vertes avec skips; installation avec neuf scripts de build ignorés; exécution sous Node 26.4.0, pertinent pour le crash libuv mais conforme à `node >=22`; le plan `~/.Codex/plans/nodalai-migration-plan.md` annoncé comme source de vérité est absent. Le fixture initial Dev C portait `code-task` mais son runtime `claude-code` ne l’exposait pas; CORE-01 a nécessité un agent Nodal temporairement configuré. Toutes les affectations/règles temporaires ont été restaurées, la stack est arrêtée. Deux preuves restent dans le workspace agent : `nodal-085-core-proof.txt` et `nodal-085-spreadsheet-proof.xlsx`.
